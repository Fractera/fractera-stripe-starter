# Step 3 — the door GET /api/stripe-products: the products and prices of the node's Stripe account

**What.** A new node door `GET /api/stripe-products` (node step 577, the need `need-20261024-a25953` from the core): it lists the products
of the owner's Stripe account with their prices, grouped under each product. Read only: nothing is created, changed or deleted.
Input `active` (`true` by default · `false` · `all`) and `limit` (1–100, default 20). Output `{ products: [{ id, name, description,
active, prices: [{ id, active, unit_amount, currency, recurring }] }], has_more }`.

**How.** Made by `npm run door:add` (`--method GET`); the work is `app/api/stripe-products/stripe-products.mjs`, `handle(input, deps)`. It
takes the client from `lib/stripe/stripe.mjs` (`stripeOrNull()`), so without keys it answers `503 no_stripe_keys` like the other payment doors.
Two Stripe calls: `products.list` (with the `active` filter and `limit`) and `prices.list` (limit 100), prices grouped by product id.
Errors: `422 bad_active` / `bad_limit` for input it cannot use, `502 stripe_refused` with Stripe's reason.
